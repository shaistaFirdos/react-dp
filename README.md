# ✅ React To-Do List Application

A simple and functional **To-Do List app** built with **React** and styled with **Tailwind CSS**.  
This app supports striking completed tasks, task history, and full **CRUD (Create, Read, Update, Delete)** operations for managing tasks efficiently.

---

## ✨ Features
- ➕ Add new tasks to your list  
- ✅ Mark tasks as completed (strike-through effect)  
- 📜 View task history of completed items  
- ✏️ Edit existing tasks  
- ❌ Delete tasks  
- 🎨 Clean and responsive user interface  

---

## 🛠️ Technologies Used
- **React (JavaScript)**
- **Tailwind CSS**
