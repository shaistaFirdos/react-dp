React To-Do List Application

A simple and functional To-Do List application built with React. This app supports features like striking completed tasks, task history, and CRUD (Create, Read, Update, Delete) operations for managing task items efficiently.

Features
Add new tasks to your to-do list
Mark tasks as completed with a strike-through effect
View task history for completed items
Edit and delete existing tasks

Simple and clean user interface



Technologies Used
React (JavaScript)
Tailwind
